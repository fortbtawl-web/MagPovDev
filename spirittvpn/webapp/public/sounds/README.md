# Звуки интерфейса

По умолчанию звуки синтезируются в браузере (Web Audio API), поэтому аудиофайлы не нужны.

Чтобы заменить синтезированный звук своим файлом:

1. Положите короткий (≤ 1 с, ≤ 50 КБ) файл `.mp3` или `.ogg` в эту папку, например `success.mp3`.
2. Добавьте его в `SOUND_FILES` в `webapp/src/sound.ts`:

   ```ts
   const SOUND_FILES: Partial<Record<SoundName, string>> = { success: "sounds/success.mp3" };
   ```

3. Пересоберите фронтенд: `npm run build`.

Доступные имена: `open`, `tap`, `connect`, `purchase`, `error`, `complete`.
Звуки играют только после первого касания пользователя и полностью отключаются в «Профиль → Звуки интерфейса».
