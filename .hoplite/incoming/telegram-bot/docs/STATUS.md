## Что сделать владельцу

1. **Перевыпустить токен бота** (@BotFather → `/revoke`), если он был отправлен где-то в открытом виде, и записать новый только в `.env`.
2. Узнать свой Telegram ID и указать его в `ADMIN_IDS`.
3. Решить вопрос с серверами: переустановка под H1//VLESS (разрушительная операция, только по вашему решению). Затем передать URL API и токены нод → `VPN_NODES`, `VPN_NODE_*_TOKEN`.
4. Подключить ЮKassa → `PAYMENT_PROVIDER=yookassa`, `YOOKASSA_*`, URL уведомлений.
5. Взять сервер для бота и панели, домен и HTTPS (`docs/DEPLOY_LINUX.md`), задать `WEBAPP_URL` и `PUBLIC_BASE_URL`.
6. В панели проверить ноды («VPN-инфраструктура → Проверить сейчас»), задать лимиты устройств для тарифов 3 мес., 1 год и Lifetime, указать `SUPPORT_URL`.
7. Проверить сквозной сценарий на себе: пробный период → ключ подключается → покупка минимального тарифа в боевом магазине → продление → отзыв устройства.
8. Настроить ежедневный бэкап (`docs/BACKUP.md`).

## Известные ограничения

- FSM бота и rate-limit API хранятся в памяти: запускайте по одному процессу бота и API.
- У Lifetime-ключа на ноде есть технический срок (по умолчанию 365 дней), который продлевается автоматически, пока работает воркер. Нода H1//VLESS не умеет «бессрочно».
- Возврат платежа отмечается в БД и уведомляет админов, но подписку автоматически не отзывает.
- Защиты от мультиаккаунтов нет; есть ограничения и ручная отмена начислений.
- Официальной документации API H1//VLESS нет. Контракт может измениться с обновлением ноды; адаптер изолирован в `backend/integrations/vpn/h1vless.py`.
