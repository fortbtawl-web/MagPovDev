# Сайт SpirittVPN

Статический лендинг без сборки и зависимостей: `index.html`, `style.css`, `app.js`, `config.js`.

## Настройка
Откройте `config.js`: `botUsername` (имя бота без @), `apiBase` (адрес backend для загрузки тарифов; пусто = тот же домен), `supportUrl` (необязательно). Секретов в сайте нет.

## Тарифы
Сайт берёт тарифы из `GET /api/plans` вашего backend, так что цены меняются в админ-панели без правки сайта. Если backend недоступен, сайт честно пишет об этом и ведёт в бота. Цены в код не зашиты.

## Размещение
- **Вместе с backend** (проще всего): положите папку в `website/` рядом с проектом. Backend раздаёт сайт по адресу `/site/` (при `SERVE_FRONTEND=true`), `apiBase` оставьте пустым.
- **На отдельном хостинге** (GitHub Pages, Netlify, Cloudflare Pages, nginx): загрузите содержимое папки, в `config.js` укажите `apiBase` вашего backend и добавьте домен сайта в `CORS_ORIGINS` в `.env`.

Локальный просмотр: `cd website && python -m http.server 8000` (тарифы при этом подгрузятся, только если указан `apiBase` и разрешён CORS).
